MYSTERY SHOP — GAME GABUNGAN (jalan-jalan + soal SPLDV + GeoGebra)

Isi folder: index.html, style.css, game.js

CARA MENCOBA DI KOMPUTER
Ekstrak ZIP, lalu buka index.html dengan Chrome (perlu internet untuk GeoGebra).

CARA PASANG DI GITHUB PAGES
1. Buat repository Public baru di GitHub (mis. mystery-shop).
2. Upload ketiga file (index.html, style.css, game.js) ke root repository.
3. Settings > Pages > Source: "Deploy from a branch" > Branch: main, folder / (root) > Save.
4. Tunggu 1-2 menit. Link: https://USERNAME.github.io/mystery-shop/

CARA MAIN
WASD / panah = jalan, E = interaksi dengan toko, Esc = tutup soal.
Urutan misi: Stationery Shop -> Fruit Shop -> Checkout Counter.
Jawaban Level 3 boleh ditulis 48000 / 48.000 / Rp 48.000.
